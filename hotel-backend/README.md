# hotel-backend

API REST del Sistema de Reservas de Hotel (Laravel 11, Sanctum, Spatie Permission, Reverb).

La documentación completa (arquitectura, instalación, variables de entorno, roles y pruebas) está en el [README de la raíz](../README.md).

Comandos rápidos:

```bash
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate --seed
php artisan serve
php artisan test
```
